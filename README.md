## Projects

### [Telemetry Processing Engine](https://github.com/vedantguptatech-ops/telemetry-processing-engine)

A multi-stage data-processing project combining C, Python, and SQL.

- **C:** Filters predefined telemetry records using sentinel-value and temperature-range checks, then exports valid records to CSV.
- **Python:** Orchestrates the C program, reads the generated CSV, and produces SQL `INSERT` statements.
- **SQL:** Defines a telemetry table and demonstrates analytical queries using ranking and cumulative-sum window functions.

**Current focus:** Improving error handling, documenting the pipeline, and developing automated tests.
